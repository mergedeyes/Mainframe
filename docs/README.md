# Mainframe documentation

Mainframe is a file browser for the terminal that also builds, runs, tests,
installs, deploys and releases your projects. These pages describe what it
does today, on Linux.

## Getting started

- [Introduction](introduction.md): what Mainframe is, how the screen is laid out, which projects it understands
- [Installation](install.md): build it, optional tools, `cd` on exit
- [First steps](guides/first-steps.md): a ten-minute tour, from opening a project to running its tests

## Guides

- [Files](guides/files.md): moving around, finding files, creating, renaming, copying, deleting
- [Running things](guides/running.md): build, run, test, the task picker, output tabs, watch mode, jumping to errors
- [Git](guides/git.md): the git menu, committing, branches, worktrees, GitHub repos and releases
- [Projects, notes and Claude](guides/projects.md): the project picker, notes and todos, new projects, the CLAUDE.md preset
- [Installing and deploying](guides/install-and-deploy.md): putting a binary on your PATH, deploying to a Raspberry Pi or a server
- [Cleaning up](guides/cleanup.md): getting disk space back from build output, dependencies and caches

## Reference
